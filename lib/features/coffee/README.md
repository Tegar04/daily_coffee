# Coffee

Pemilik coffee collection, coffee detail, form/draft manual, favorite, dan
coffee-specific search/filter contracts.

Phase 4 mengimplementasikan domain/application/data/presentation untuk manual CRUD
dan favorite. Mulai Phase 5, `app/composition/coffee_providers.dart` memakai
`DriftCoffeeRepository`; adapter in-memory hanya untuk test/preview. Baca
`docs/LOCAL_PERSISTENCE_IMPLEMENTATION.md` sebelum mengubah schema, repository,
atau menghubungkan journal/photo lifecycle.
